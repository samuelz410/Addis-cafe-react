# Addis Café

A static Ethiopian café menu built with React and Vite.

## Description
This project displays a responsive food and drink menu for Addis Café, showcasing functional React components, props, lists with `.map()`, and component composition without using state hooks.

## Technologies
- React
- Vite
- JSX
- CSS3

## Features
- Modular component hierarchy (`App`, `Header`, `Menu`, `MenuItem`, `Footer`)
- Dynamic rendering via props
- JSX expression calculations (15% VAT calculation)
- Category-specific card styling & emoji badges
- Fully responsive CSS Grid layout
